# Agent RAG learning path

Start with Python API development, HTTP basics, environment variables, and logging. Then learn embeddings, sparse search, vector databases, reranking, and evidence-gated answer generation.

After vector retrieval, study reranking, RAG evaluation, LangGraph orchestration, tool calling, MCP, and trace-based debugging. Build one small project at each stage: FAQ bot, error helper, code explainer, then a multi-route Agent course assistant.

If you are choosing between LangGraph and MCP, learn LangGraph first when your pain is workflow control, retries, state, and observability. Learn MCP first when your pain is connecting models to external tools, files, APIs, or desktop applications.

For a portfolio project, show measurable quality: route accuracy, citation coverage, hallucination/refusal behavior, latency, and examples where the system refuses because evidence is missing.
